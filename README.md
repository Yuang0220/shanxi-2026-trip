# 2026 国庆山西家庭旅行手册

微信网页入口：`index.html`

- `with-images.html`：图文版。沿用早期版本的图片选择；封面胶囊已删除；正文不出现具体年龄或“老人/老年人”，统一写“奶奶”。
- `text-only.html`：纯文字版。以 V6 为基础，进一步把少量双栏日程卡改为“主行程 + 底部横向信息条”，减少左右重心失衡。
- `.github/workflows/pages.yml`：GitHub Pages 自动部署，并在 GitHub 服务器端下载图文版所需原图，因此微信端不需要访问 Wikimedia。

发布后使用 GitHub Pages 的 HTTPS 地址，可直接在手机微信内打开。
