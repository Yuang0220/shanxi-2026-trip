01

先看结论

路线由北向南推进，酒店已经固定。9/26和9/30以转场、会合为主；10/1开始自驾。10/2、10/3路程较长，景点按当天路况和体力取舍。

交通10/1—10/4自驾。爸爸主驾，妈妈可轮换。
预约云冈、悬空寺登临、小西天提前确认。
10/2王家大院、广胜寺优先；大槐树视时间决定。
10/3小西天、壶口为主，不再增加景点。
10/1晋祠、双林寺优先；拥堵时镇国寺可取消。
10/4永乐宫优先级最高，再看飞云楼、关帝庙。
行李证件、充电、雨具、常用药和薄外套放在易取位置。
穿衣北段早晚凉，壶口风和水雾明显；分层穿着。

03

逐日执行手册

9/26
南京 → 大同
  • G469 南京南 14:23 → 大同南 21:57。
  • 到站后直接入住，不再安排夜游。
  • 外套、补水和零食放在手边。
9/27
云冈石窟 → 大同博物馆 → 古城
  • 云冈是当天核心，预留约2.5—3.5小时。
  • 博物馆作为室内补充；晚间古城按状态决定。
  • 凤临阁等位过长时直接换凯鸽。
时间不足：先取消晚间古城，再缩短博物馆。
9/28
应县木塔 → 净土寺 → 悬空寺 → 永安寺
  • 木塔、悬空寺整体、永安寺优先。
  • 悬空寺以山下观景为主；是否登临按预约、天气和现场状态决定。
  • 圆觉寺为机动项，排队超预期直接取消。
9/29
华严寺 → 善化寺 → 九龙壁 → 忻州
  • 上午看古城精华，下午转场忻州。
  • 华严寺优先；时间紧时善化寺、九龙壁二选一。
  • 最终车次以12306订单为准。
9/30
忻州 → 太原｜爸爸晚间会合
  • 上午在忻州古城短逛，下午妈妈和奶奶先到太原入住。
  • 爸爸按原计划 HO2325 18:50 → 20:45 到太原。
  • 当天不再增加大型景点，安排洗衣、充电和休息。
10/1
晋祠 → 镇国寺 → 双林寺 → 平遥
  • 晋祠、双林寺优先，镇国寺视路况决定。
  • 国庆首日把停车和高速拥堵算进行程。
  • 入住后只安排轻松散步。
10/2
王家大院 → 广胜寺 → 隰县
  • 当天路程较长，王家大院、广胜寺优先。
  • 洪洞大槐树只在进度宽松时加入。
  • 爸爸上午主驾，妈妈可主动轮换一段。
到隰县后直接入住，不再增加晚间活动。
10/3
小西天 → 壶口瀑布 → 万荣
  • 小西天按预约入园；台阶和人流密度较高时缩短停留。
  • 壶口按景区摆渡和安全动线游览。
  • 到万荣后直接入住，飞云楼留到第二天。
10/4
飞云楼 → 永乐宫 → 广仁王庙 → 解州关帝庙 → 运城
  • 永乐宫是当天第一优先级，留足参观时间。
  • 广仁王庙根据当天进度决定。
  • 晚上入住运城盐湖区希尔顿欢朋。
10/5
运城 → 南京
  • 按原计划约10:20 → 12:10返南京，最终以订单为准。
  • 早餐后前往机场，预留还车、行李和安检时间。

05

餐饮参考

大同

凤临阁 / 凯鸽二选一。可尝烧麦、浑源凉粉、过油肉、刀削面；节假日不为名店长时间排队。

平遥

洪武记 / 天元奎二选一。另一顿安排碗秃、面食或家常菜即可。

忻州

莜面、抿尖、碗托、羊杂等，就近选择。

晋南

长距离转场日优先顺路、少等位、有热菜的餐厅。
