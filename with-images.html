万荣 / 芮城 / 运城整体比北段温和。继续分层，不需要因南段单独加厚重冬装。
天气更新：出发前7-10天看趋势；前3-5天用逐日预报决定雨天替换。现在不以一个月后的“某天晴/雨”调整路线。

9/26周六

中秋假期
南京南→大同南→大同古城酒店
  • 7个半小时左右久坐是当天主要负担；车上每隔一段时间起身活动、补水。
  • 到大同后直接入住。晚到后不安排古城夜游，把睡眠留给9/27云冈。
  • 大同晚间温度可能明显低于南京，外套不要塞在托运行李最底层。

9/27周日

云冈石窟 → 大同博物馆 → 大同古城

中秋假期最后一天｜云冈预约决定当天节奏
客流高
一级核心云冈石窟
稳定补充大同博物馆
弹性体验古城散步/晚饭
  • 云冈是当天唯一不可被“赶”的项目；中秋客流中，预约、入园和讲解都要留余量。
  • 博物馆是很好的体力缓冲：室内、可坐、信息量高；之后回酒店稍休息再看古城。
  • 如果晚上状态好，把代王府/乾楼的外部和街区顺手看掉，为9/29减负。

吃饭策略：想吃凤临阁可以，但国庆/节假日有长时间排号记录；排队过长直接换凯鸽酒楼，别用两三个小时换一顿名店。
9/28周一

应县木塔 → 净土寺 → 悬空寺 → 永安寺 → 圆觉寺

包车｜“走一段 - 坐一段”包车转场，路上可休息
中高强度
大同→应县→浑源→大同

执行

  • 核心 应县木塔、悬空寺整体、永安寺。
  • 次核心 净土寺。
  • 机动 圆觉寺：悬空寺排队超预期就直接取消。

木塔拍摄：人多时低机位仰拍能把游客压到画面底部；1×拍完整比例，2×/3×拍檐口层叠。2026年已有数字沉浸式“云登塔”体验，可作为不能登高层的补偿项。

9/30周三

忻州 → 太原｜爸爸晚间会合

妈妈+奶奶：动车转场；爸爸：南京→太原 HO2325 18:50-20:45（按原表）
恢复日
  • 上午只做忻州古城的慢节奏体验；下午妈妈和奶奶去太原入住。
  • 爸爸是国庆前一日晚进城，机场到酒店的城市交通不要按普通晚间最短值预估。
  • 当天不再安排山西博物院、太原古县城等大型项目。这一天作为前后两段之间的恢复日很有价值。
忻州安排：逛一点、吃一点、回酒店温泉。重点尝莜面、抿尖、碗托、瓦酥、羊杂，不需要为单一网红店跨城折腾。
住宿
卡曼·观博设计师酒店（山西博物院吾悦广场店）｜表内 ¥512。新、评价好、洗衣和停车便利；但无早餐、精品设计酒店标准化弱于连锁。只住一晚问题不大，提前要安静、离电梯方便的房间。
10/1周四

晋祠 → 镇国寺 → 双林寺 → 平遥古城

爸爸加入后的第一天自驾｜重点关注高速与停车
国庆首日
  • 表内纯驾驶约1h47，但国庆规划应把道路、停车、收费站余量理解为约2.5-3.5h级别，而不是“准点表”。
  • 晋祠、镇国寺、双林寺内容差异大，不建议提前机械二选一。
  • 如果太原出城/G5方向已经损失大量时间，镇国寺先转机动；双林寺离平遥更近，保留更稳。
  • 进入平遥后停车、民宿接行李、入住完成，再把古城当散步项目，不追求再“清景点”。
晋祠机位：水镜台正面轴线；圣母殿拍柱列/檐口；鱼沼飞梁利用几何关系；古树+建筑比单拍殿宇更有年代感。
平遥拍照：真正出片时段是傍晚蓝调与亮灯后。南大街用2×/3×压缩市楼与街道；主街太挤就进支巷拍灰墙、木门、红灯笼。
10/2周五

王家大院 → 广胜寺 → 洪洞大槐树（机动）→ 隰县

全程最需要纪律的一天｜约291km表内里程
全程最高负荷
  • 表内理论驾驶约4h04；国庆按5-6h+的道路/停车缓冲更稳妥。
  • 王家大院本身步行、台阶和院落尺度都大，是当天最大的体力项目。
  • 王家大院 + 广胜寺 = 核心组合。洪洞大槐树是Bonus，不是KPI。
  • 出现任一情况——G5明显拥堵、下雨、奶奶明显疲劳、爸爸驾驶疲劳——直接取消大槐树，去隰县。
  • 妈妈在王家大院之后主动接一段高速，比等爸爸“实在不行了”再换更合理。
避免最常见错误：不要把已经损失的堵车时间从广胜寺和王家大院的游览中平均挤回来；直接删大槐树。
穿衣出片：灰砖木构背景下，米白、酒红、墨绿、深蓝、驼色更突出；全灰/全黑容易“融”进建筑。
10/3周六

小西天 → 壶口瀑布 → 万荣

两个热门点叠加｜不加第三个游览项目
客流+停车高波动
  • 小西天必须按7日预约规则提前锁定。狭窄台阶、殿内人流密度比“走了多少公里”更影响奶奶。
  • 悬塑空间先看、再拍；若允许摄影也不闪光、不举自拍杆堵通道。
  • 表内小西天→壶口约131km、壶口→万荣约122km；国庆真正耗时常在景区出口、收费站、停车和摆渡。
  • 到万荣后即使天还亮，也不要提前加飞云楼；留给10/4。
壶口黑科技：Live Photo/连拍；人物退离瀑布一点，让“人+黄河+落差”都进入画面。水雾会不断糊镜头，镜头布放裤袋里，拍几张擦一次。
吃饭：如果在壶口附近正好顺路，冯记鱼府可尝黄河鲤鱼/黄河虾；但不要为餐馆倒逼行程。奶奶吃鲤鱼注意鱼刺。

10/5周一

运城 → 南京｜低风险收尾

原表航班约10:20-12:10｜不要晨间加景点
低
  • 最后一天只做退房、去机场、返程。国庆尚未结束，交通要留余量。

06｜摄影机位速查：不为拍照额外透支体力

地点优先机位 / 构图镜头避坑
云冈20窟露天佛；连续崖壁；窟檐框景1×环境，2×人物+佛，3-5×细节禁闪光区严格遵守；不要每窟都拍同一种正面照
应县木塔低机位正面；门洞框塔；红墙+塔1×整体，2-3×檐层0.5×容易把塔拍歪；人多就降低机位
悬空寺下方拍山体+整寺1×环境，3×建筑，5×细节“登上去”反而拍不出悬空关系；奶奶无需登也能拍最好全景
华严/善化院落中轴偏1/3；门洞；红墙1×/2×人物不要占画面一半以上
晋祠水镜台；圣母殿柱列；鱼沼飞梁；古树+殿宇1×/2×不要只拍“庙门身份证照”
平遥南大街蓝调；市楼压缩；支巷红灯笼2-3×最好用正午主街最拥挤、光也硬
王家大院高处灰瓦层叠；门洞；长巷1×/2×每个院子重复拍会快速消耗体力
小西天以观看悬塑为先允许时用2-3×不闪光、不自拍杆、不在人流瓶颈停留
壶口人物+黄河+落差；彩虹1×/2×，连拍/Live镜头水雾必须频繁擦
飞云楼中距离整楼；斗拱、翼角1× + 3-5×贴楼底0.5×畸变强
永乐宫室外中轴、宫墙、殿宇1×/2×官方：大殿内严禁拍照
关帝庙中轴、牌坊、红墙、琉璃1×/2×强光下利用廊下阴影/门洞，不让奶奶久站暴晒
手机摄影最有效的“黑科技”：人多景区不要迷信0.5×。用2×/3×主动裁掉两侧游客、压缩人物与建筑；国庆比后期P掉几十个人更实用。

08｜随车与随身清单

证件 / 预约
三人身份证原件；预约截图离线保存；小西天/云冈免票奶奶也按规则实名预约。
手机 / 导航
高德+百度都保留；下载山西离线地图；充电宝；车载快充；停车场作为导航终点而非只搜景区名。
衣物
薄长袖、中层、轻防风防水外套；奶奶额外暖中层；已经磨合好的防滑鞋。
车里常备
小瓶水、纸巾、湿巾、一次性雨衣、坚果/小面包/巧克力；不用每人背一大包。
摄影
镜头布（壶口刚需）；手机挂绳可选；不要为了拍照带笨重三脚架进入拥挤景区。
奶奶舒适
排队时优先找座位/休息区；是否携轻便坐垫看景区规定。每天晚上观察第二天恢复状态，而不是只看当天“走得动”。
